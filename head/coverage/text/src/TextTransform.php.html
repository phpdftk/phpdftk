7/**
8 * CSS Text 3 §2.1 — `text-transform`, applied to a text run before
9 * shaping.
10 *
11 * Shared because both text pipelines need it: HTML inline layout, and
12 * the SVG painter for `<text>`. They used to be the same algorithm in
13 * only one of them.
14 *
15 *  - `uppercase` / `lowercase` are full Unicode case mappings.
16 *  - `capitalize` upper-cases the first grapheme of each
17 *    whitespace-separated word, preserving the original separators.
18 *  - `full-width` (CSS Text 4 §2.1.4) maps ASCII U+0021..U+007E to the
19 *    full-width forms U+FF01..U+FF5E, and ASCII space to the
20 *    ideographic space U+3000.
21 *  - Anything else — `none`, `full-size-kana`, an unknown keyword —
22 *    passes through unchanged.
23 */
