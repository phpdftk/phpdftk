17/**
18 * Hands the HTML document's font machinery to SVG text painting.
19 *
20 * SVG 2 §11.5 defers font selection wholesale to CSS Fonts 4, so
21 * `<svg><text>` in an HTML document selects from exactly the same face
22 * set as the surrounding HTML — `@font-face` families included. Without
23 * this bridge the SVG translator falls back to its standalone
24 * standard-14 mapping and a `font-family: Ahem` run paints in
25 * Helvetica while the neighbouring `<div>` paints in Ahem.
26 *
27 * Matching runs through the layout {@see FontResolver} so weight and
28 * style selection follow the same CSS Fonts 4 §6 rules as HTML text.
