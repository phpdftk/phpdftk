170        $currentY = $y;
171        // CSS Shapes 1 — `shape-outside` defines the float area that
172        // excludes LINE BOXES; it does not move the float itself or change
173        // how floats stack against each other, which CSS 2.1 §9.5.1 settles
174        // with margin boxes. So this search is deliberately shape-blind:

548     *
549     * Between two consecutive vertex ordinates the set of edges crossing a
550     * scan line is fixed and each crossing is LINEAR in y, so the band's
551     * right-most crossing is a max of linear functions — convex, hence
552     * maximised at a sub-interval endpoint. Evaluating at the band's own
553     * ends plus every vertex ordinate strictly inside it is therefore exact,
554     * not a sample. (The left-most crossing is the mirror: a min of linear
555     * functions is concave and minimised at the same points.)

585     * for a right float, the left-most crossing pulls it back.

617                || (!$max && $x < $best)
