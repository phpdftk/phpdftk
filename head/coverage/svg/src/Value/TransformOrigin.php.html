8 * The `transform-origin` presentation attribute / CSS property for SVG
9 * elements (CSS Transforms 1 §6).
10 *
11 * SVG elements have no associated CSS layout box, so their used initial
12 * `transform-origin` is `0 0` rather than the `50% 50%` that applies to
13 * CSS boxes — an element with no `transform-origin` pivots on its
14 * reference box's origin instead of its centre.
15 *
16 * Everything here is an offset from that reference box: percentages
17 * resolve against its size, lengths are a plain offset from its origin,
18 * and position keywords name its edges. WHICH box that is comes from
19 * `transform-box` (CSS Transforms 1 §7) and is the caller's business —
20 * this class only resolves against the rectangle it is handed.
21 *
22 * Only the first two components are meaningful; a third (Z) component
