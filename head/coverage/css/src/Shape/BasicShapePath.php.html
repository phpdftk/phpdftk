22/**
23 * CSS Shapes 1 §3 / CSS Masking 1 §6 — resolve a `<basic-shape>` against a
24 * reference box into a flat outline.
25 *
26 * The result is pure geometry: absolute coordinates in the reference box's
27 * own space, with x running right and **y running down** (the CSS
28 * convention). Renderers map that into their own space — the HTML painter
29 * flips y against the page height, the SVG translator hands it straight
30 * through because its base matrix already carries the flip.
31 *
32 * Curves are pre-flattened to cubic Béziers so a consumer only has to
33 * understand four commands:
34 *
35 *   - `['M', x, y]`                          move to
36 *   - `['L', x, y]`                          line to
37 *   - `['C', x1, y1, x2, y2, x, y]`          cubic curve to
38 *   - `['Z']`                                close the subpath
